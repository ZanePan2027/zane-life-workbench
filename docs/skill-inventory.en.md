# Skill directory

Start with `zane-workbench`. It selects the methods needed for your task. Use a specific entry below when its purpose fits.

[简体中文](skill-inventory.md) · [Walkthrough](guide.en.md)

## [Main entry](../skills/zane-workbench/SKILL.md)

`zane-workbench`

Use when: Understanding a situation, comparing choices, planning, or completing a task.

```text
Use zane-workbench. Compare both jobs against my budget and weekly schedule.
```

Output: Tradeoffs, useful work, and next steps.

## [Question clarification](../skills/zane-question-intent-translator/SKILL.md)

`zane-question-intent-translator`

Use when: Separating several concerns to identify the task at hand.

```text
Use zane-question-intent-translator. I am worried about changing jobs, income, and time. Help me identify the current decision.
```

Output: The current question, needed judgments, and a request you can continue with.

## [Self-reflection](../skills/zane-self-insight/SKILL.md)

`zane-self-insight`

Use when: Exploring motives, values, or recurring choices through experience.

```text
Use zane-self-insight. Use these experiences to explore what matters to me when I choose.
```

Output: Grounded, tentative insights, open questions, and practical experiments.

## [AI partner setup](../skills/zane-agent-identity-card-builder/SKILL.md)

`zane-agent-identity-card-builder`

Use when: Defining how an ongoing AI partner should work with you.

```text
Use zane-agent-identity-card-builder. Help me define an AI partner that can disagree, explain its evidence, and save progress.
```

Output: Responsibilities, reasoning approach, communication, and memory arrangements.

## [Set up, organize, and continue](../skills/zane-workbench-curator/SKILL.md)

`zane-workbench-curator`

Use when: Setting up a workspace, organizing sources, saving work, or resuming.

```text
Use zane-workbench-curator. Set up a workspace in this folder, organize access and references to existing material, and continue the current task.
```

Output: Relevant sources, current work, task state, and a continuation entry.
