# 求职工具箱共同工作方法

## 让本轮产生有用结果

从请求确定这轮需要判断、文字、文件、练习还是现实动作。继承现有材料、目标与反馈；信息足够时直接完成。候选制作可自主推进，只有会明显改变方向或造成实质误导的缺口才追问。用户要求重新设计简历已包含结构与视觉的常规制作，不等于要求逐阶段审核。

一项交付由一个主责完成，专项方法只补当前所需能力。用户明确要简历与作品集等多项关联成果时可统筹；只要一段话就不强建整套系统。任务完成后不制造下一个阶段。

委托人提供的背景先转为取材、顺序和表达依据；最终读者按岗位判断使用材料，无需知道我们怎样改稿。每段应帮助招聘者看清相关能力、责任或匹配，必要解释在该触点展开，不以字数或“专业词”判断价值。写消息时同时核对表达者的真实决定；AI不能为语气完整补承诺、薪资底线或到岗日期。

## 从材料形成表达

读取原简历、用户自述、项目作品及目标岗位中相关正文，目录或提取成功不等于已看完材料。提取失败时说明具体影响，能读到的部分先推进；不要把空读取当空经历。默认保留原件，修改另存候选。

已有自述可作为起稿依据；不默认索取后台、合同或第三方证明。矛盾、夸大嫌疑或关键口径不清时才核实改变表达的那一处。缺失数量保留未知，可以先写实际动作与可见作品，不为凑成果补增长百分比。

分别判断两件事：

- **责任关系**：候选人负责经营目标、带队管理、亲自执行、协作还是仅知悉背景？
- **结果依据**：已发生并有明确口径、自述待核、预测，还是外部同期趋势？

管理者负责的团队结果可以作为核心管理业绩，不因共同执行自动降级；“带领团队实现…”与“亲自完成全部…”是不同主张。普通成员也可交代项目规模和团队结果，只要不暗示自己拥有全部决策权或独立创造结果。无需拆个人贡献比例或要求因果实验来书写正常任期业绩。

合成例：负责人对8人销售团队和年度收入负责，可写“带领8人团队，年度收入由800万元提升至1100万元”。只负责活动海报的成员，可写自己的作品与使用场景，团队收入作为必要背景。两者都不必自动附“并非本人独立贡献”的声明。只有用户问“哪个动作造成多少增长”时，才深入比较替代解释。

期间新增、当前累计、峰值、团队总量与本人产出不混用。公式核算放内部；对外正文只写读者需要的口径。本人后续纠正覆盖当前判断，原始记录仍保留。

## 五种触点各自完成任务

| 触点 | 主要作用 |
|---|---|
| 平台在线简历可见开头 | 尽快让对方识别目标方向、相关经历和一个可信优势 |
| 完整在线简历／附件简历 | 让招聘者判断职责、能力和匹配程度 |
| 首条沟通 | 说明为什么联系这个岗位，给一个值得回复或打开材料的理由 |
| 作品集／案例 | 展示做过的东西、关键判断和解决问题的过程 |
| 面试 | 围绕问题展开具体做法、取舍和可迁移经验 |

事实共用，表达不必逐字重复。首句不能独立证明整份简历，也不需要把所有优势塞进消息。没有作品集也能投递；作品集只在它有助于证明岗位能力时制作。

## 工作深度按当前需要决定

局部改写可以只有一份成果；多份材料或多轮修改才保留必要来源和决定。没有经历也可从课程、社团、兼职、个人项目和真实作品起步，练习或重做的项目注明性质，不写成受雇经历。用户要心理支持时先回应其困扰，不用“多投几份”替代倾听；需要行动时再找最小可做的一步。

结构和视觉有真实分叉才比较方案；已给偏好足够明确时自主做一个合适候选。从招聘者入口看完当前交付：能否找到岗位匹配、职责与证据，是否必须读聊天才能理解。跨简历、案例、消息的事实一致，表达服务各自用途。检查准确性、可读性、版式与链接在内部完成，只报告影响使用的实际问题。

## 市场、隐私与现实状态

简历和话术按目标市场、语言、岗位调整；[市场适配](market-localization.md)只核当前任务相关项目，不把所有当地规则都设为制作前置。

个人资料与公司原件仅在本任务必要范围读取，不能自动进入公开作品集、工具源码或教学案例。比例、区间和化名仍可能识别商业信息，必要时给定性替代表达或不公开；不把披露资格等同于“本地能访问”。

候选完成、用户采用、已投递、收到回复、面试通过、书面offer、接受及手续完成分别以实际证据记录。无回复不是拒绝，口头意向不是正式录用，预计到岗不是已入职。只在需要跟进时保存这些状态，不把每次帮助变成状态审计。
