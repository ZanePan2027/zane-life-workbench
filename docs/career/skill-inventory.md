# 能力目录

第一次从 `zane-career-assets` 开始，由它按任务选择方法。熟悉后，可以直接使用下面的入口。

[English](skill-inventory.en.md) · [完整使用示例](guide.md)

## [统一入口](../../skills/zane-career-assets/SKILL.md)

`zane-career-assets`

适用：方向选择、找岗位、招聘平台资料与沟通、简历作品集、笔面试、offer、谈薪和入职前准备。

```text
请使用 zane-career-assets，这是我做过的事和两份岗位说明，请帮我比较。
```

产出：当前任务需要的判断、文件、文案或逐轮练习；默认直接完成，不要求先建工作台。

## [整套求职材料](../../skills/zane-career-portfolio-builder/SKILL.md)

`zane-career-portfolio-builder`

适用：需要一起完成简历、作品集和投递入口。

```text
请使用 zane-career-portfolio-builder，根据这个目标岗位和这些材料，安排并制作我需要的求职材料。
```

产出：各载体分工、内容、设计与交付文件。

## [简历制作](../../skills/zane-career-resume-builder/SKILL.md)

`zane-career-resume-builder`

适用：从零做简历，或按招聘市场和语言重写。

```text
请使用 zane-career-resume-builder，用这些经历做一份申请产品实习的英文简历。
```

产出：简历内容、版式及宿主可生成的编辑稿和PDF。

## [作品集结构](../../skills/zane-career-portfolio-architecture/SKILL.md)

`zane-career-portfolio-architecture`

适用：已有多个项目，需要安排招聘者的阅读顺序。

```text
请使用 zane-career-portfolio-architecture，这三个项目放进作品集，首页和案例页分别讲什么？
```

产出：首页、深读案例与项目索引的结构。

## [作品集网站](../../skills/zane-career-portfolio-website-design/SKILL.md)

`zane-career-portfolio-website-design`

适用：需要设计或实现职业作品集网页。

```text
请使用 zane-career-portfolio-website-design，根据已确认的项目内容制作作品集网站。
```

产出：页面设计、响应式实现和本地文件。

## [中文案例编辑](../../skills/zane-career-case-editor-zh/SKILL.md)

`zane-career-case-editor-zh`

适用：案例事实已确认，需要整理叙述与语言。

```text
请使用 zane-career-case-editor-zh，保留事实，把这篇项目案例写得更清楚，删掉空泛的总结。
```

产出：保留事实的案例改稿与必要修改说明。

## [贡献与结果表达](../../skills/zane-evidence-weighted-case-storytelling/SKILL.md)

`zane-evidence-weighted-case-storytelling`

适用：需要准确呈现领导责任、团队协作、实际结果或同期变化。

```text
请使用 zane-evidence-weighted-case-storytelling，按我的真实职责把这份案例改成有说服力的求职表达。
```

产出：职责与证据相符的案例；负责人的团队业绩不因共同完成自动降级。

## [前雇主材料处理](../../skills/zane-former-employer-data-redactor/SKILL.md)

`zane-former-employer-data-redactor`

适用：准备展示含前雇主业务信息的案例。

```text
请使用 zane-former-employer-data-redactor，检查这个案例哪些内容适合公开，哪些需要替换或留到面试展开。
```

产出：材料审阅、替代表达与发布范围建议。

## [投递第一句话](../../skills/zane-career-application-greeting/SKILL.md)

`zane-career-application-greeting`

适用：向招聘者或猎头发送首次联系消息。

```text
请使用 zane-career-application-greeting，根据这个岗位和我的简历，写一条简短的中文打招呼语。
```

产出：对应岗位、渠道和语言的消息草稿。

## [交付检查](../../skills/zane-portfolio-multi-format-qa/SKILL.md)

`zane-portfolio-multi-format-qa`

适用：简历、网页或作品集完成后检查实际成品。

```text
请使用 zane-portfolio-multi-format-qa，检查这份PDF和作品集网页的版式、链接和手机显示。
```

产出：实际检查结果、问题位置与未能检查的项目。

## [视觉参考转译](../../skills/zane-design-reference-to-prompt/SKILL.md)

`zane-design-reference-to-prompt`

适用：已有网页或截图参考，需要明确设计要求。

```text
请使用 zane-design-reference-to-prompt，把这个参考页面拆成可以用于我作品集的设计要求。
```

产出：视觉关系说明与可执行的设计要求。
