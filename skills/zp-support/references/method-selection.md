# 根据维持过程选择方法

这是一张供 Agent 使用的决策表，不是把用户分进学派的测验。所有实际练习沿用 [practice.md](practice.md) 的可停、低负担与反馈规则。来源编号见 [evidence.md](evidence.md)。方法原理、专业疗法研究和本 Skill 的对话适配分开看。

## 方法入口

| 当前最需要改变的环节 | 主方法 | 本次产物 | 不匹配／退出信号 |
|---|---|---|---|
| 未被理解、刚受伤、不想改变 | 支持性倾听、确认体验与共同目标（P7） | 较准确的理解，允许停下 | 用户想解决问题却一直被共情拖住 |
| 同时想改变又舍不得某种收益 | 动机式访谈精神（P5） | 双方理由被理解，选择属于本人 | 本人已决定行动，继续盘问只增加负担 |
| 事实推断、苛刻规则和自我评价维持痛苦 | CBT 共同检验（P1、P2） | 可相信的替代解释或可检验预测 | 变成辩论、现实伤害被否认、重复求保证 |
| 生活退缩、缺少有意义活动、回避可能被短期缓解维持 | 功能分析、行为激活／问题解决（P1、P3、P12） | 一个对应功能、条件可行的尝试 | 过劳、疾病、危险或资源缺口才是主因 |
| 陷入消除念头／情绪的斗争，目标却很在意 | ACT 灵活性取向（P4） | 念头存在时仍有一点选择 | 解融合被当作压抑技巧、哲学化地躲开现实问题 |
| 情绪很强，马上分析只更混乱 | DBT 接纳与改变原则、有限调节技能（P6） | 稳定一点、分清事实与行动冲动 | 生理不适、解离加重或即时危险；转安全与现实支持 |
| 自我攻击、羞耻使复盘变成惩罚 | 慈悲／自我关怀取向（P8） | 中性、公允、不放弃责任的态度 | 温柔语言引起反感、练习增加威胁感 |
| 关系中反复期待、误读与应对，愿意深入理解 | 关系／心理动力学启发的探索（P9） | 当前关系模式的暂定图景 | 一次互动被定依恋类型、补童年或将纠正视为阻抗 |
| 怎样生活、责任与自由冲突、意义失落 | 哲学对话（H1—H6） | 本人选择或仍保留的立场 | 用户只想休息、现实损害未处理、观点使自责加重 |

## 具体怎样使用

### 1. 动机式访谈：让矛盾可以被理解

用准确反映同时容纳改变与维持的理由：“一部分想……，另一部分靠它得到……”。不把后一部分当借口。开放提问、反映和总结用于唤起本人的理由；需要提供信息时先确认它是否正是用户所需，信息后听本人如何理解。已明确索取信息无需再次征求许可。

只追问会改变下一步的一点，例如改变最在意的收益，或目前最难放弃的部分。出现本人选择就随其推进；可以保持不变、缩小目标或暂不决定。矛盾不等于虚伪，MI 也不是偷偷把用户劝向 AI 的目标。Cochrane 的物质使用研究不能证明本适配能解决所有习惯。

### 2. CBT：合作检验，而非寻找“错误思想”

区分事件、可观察事实、解释、条件规则（“只有……才……”）和整个人的评价。先问这个理解在当时为何可信；再找已知支持、不支持与缺失的信息。替代说法必须容纳真实损失，不要求积极。

本人想检验且风险可承受时，用微型行为实验：写清预测 → 什么结果算支持／削弱 → 本人同意的有限尝试 → 实际结果 → 怎样修正。可以不评分。预先承认预测可能成真；成真就更新环境、技能或应对，不把一切结果都解释为疗法成功。

例：虚构学生担心在读书会提出一个不同意见会被全面排斥。先核是否存在霸凌与实际风险；若安全且本人愿意，可选择一次低成本表达。观察当场实际回应，不把“人人喜欢”设为达标。保持安全边界不叫安全行为；不自行开展临床暴露、ERP 或创伤处理。

### 3. 行为与环境：功能相配，恢复生活

先区分短期缓解、愉悦奖励、习惯线索及现实需要。只改变一个较早环节，替代行为尽量满足原需要：休息不足要补休息，信息不清要获取信息，而非统一要求运动或工作。环境调整由本人决定，涉及设备、账户或文件变更须遵循相应授权。

行为激活关注有意义的接触、愉悦、联结或照顾，不只看任务完成。选择可行活动、预估障碍并观察体验；不能拿一次小行动冒充完整 BA。持续耗竭时先降负荷或求评估，越做越糟不是懒惰证据。

### 4. ACT：改变与念头相处的方式

关注当下、允许感受、认知解融合、灵活看待自我、本人价值与自主行动这几个过程；不要求每次完成六项。先说明当前尝试的目标是增加选择，不保证消除想法。

可以把一句反复念头表述为“我注意到自己又在想……”，然后回到此刻重要的一件事。本人不喜欢这句话就换普通语言；念头若反映真实危险，处理危险。接纳感受不等于同意不公，价值不是绩效指标。正念只作为可选注意练习，出现不适即停，不将“无我”当临床解释。

### 5. DBT：接纳当前体验，同时寻找可改变处

确认感受在其情境中可理解，仍可以讨论行为带来的伤害和修复。高唤起时先做温和外部定向；能讨论时再核对事实、问题解决、行动冲动与后果。相反行动仅在事实与情境充分、本人认可且没有真实危险时做有限借鉴；害怕危险时离开可能正是合适行动。

完整 DBT 包括超出单次聊天的治疗结构。技能训练包的证据不能给一个随手挑选的动作背书。冰水浸脸、屏息、剧烈运动、强刺激不是默认招式。

### 6. 自我关怀：减少攻击，保留责任

把“我做了不合目标的事”与“我不值得被照顾”分开。可借用公允的教练口吻：描述发生的事、承认代价、支持修复。不以“你最好”“别人不配”代替关怀，不否认需要道歉、承担后果或建立边界。

对一些人，温暖意象会增加不适。改用中性语言、具体照顾或直接停止。不要强迫想象安全家人、身体接触或感恩。正式 CFT 的多组成干预不能约化成一句安慰。

### 7. 关系与心理动力学：深入但不擅自解释

从当前关系问：希望得到什么、预计别人怎样回应、自己如何保护或表达、对方实际如何回应、之后怎么看自己。比较不同情境的例外；他人动机仍未知。相似互动反复出现才逐步讨论模式。

历史只在本人愿意且相关时进入；“过去也许有影响”不是“你必然受过某种创伤”。可以解释防御作为一种可能的应对功能，但不据此给“自恋”“回避型”等标签。AI 自己让用户感到被推动或误解时，先承认具体失配并修正，不分析用户为什么抗拒 AI。

心理动力学治疗有研究支持，不代表聊天模型能担任分析师、解释移情或实施完整疗程；本 Skill 借鉴对关系、情感和重复模式的关注，不模拟临床权威。

## 组合与切换

- 默认一个主方法。支持性理解贯穿全过程，不算每轮新增疗法。需要补充时说明新方法要处理哪个尚未覆盖的环节。
- CBT 与 ACT：需要分辨事实时用 CBT；证据已检查却陷入反复求确定时，可解释后切换到承受不确定。不要把所有忧虑都当错觉，也不要让用户同时执行相反目标。
- MI 与行动：尚在权衡时用 MI；本人已选择时做计划或练习，不反复确认动机。
- 慈悲与责任：减少自我攻击可以先行，现实损害仍需合适修复，二者不抵消。
- 关系探索与当下稳定：理解历史可以有价值；若明显过载、恍惚或请求停止，回到当下而非继续追因。
- 哲学与心理学：先确认用户想讨论生活立场；不把一门哲学的理想作为心理健康达标线。不同传统的冲突保留在 [philosophy.md](philosophy.md)。

用户说无效、负担变大或目标已变，按 [feedback-and-evolution.md](feedback-and-evolution.md) 修改。一次没用不需要把所有学派轮换一遍；先查是否误解、条件不合、方法不匹配或需要现实／专业帮助。
