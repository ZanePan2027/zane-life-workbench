# Start in an ordinary chat

You can begin with the simplified prompt below.

For the complete Skill, follow the [installation guide](install.en.md) in a tool that supports Agent Skills. If the environment can read repository files, ask the Agent to start with the [main entry](../skills/zane-workbench/SKILL.md) and read the referenced methods needed for the task.

## A simplified starting prompt

Describe your current concern, adding material if you have it. Or start with:

```text
Work and caring for family fill my week. I want one evening for myself.
Help me find one workable step without asking for a full life profile.
Use what matters to me, my current conditions, and resources I can actually use.
Give a usable judgment or draft, asking only for facts that change the next step.
Revise the plan when new information arrives.
```

Continue by asking for a draft, another option, or an explanation of the judgment.

## Continue later

Before pausing, ask for a note containing the current work, decision, facts used, and next step. Save it yourself and paste it into the next chat with the relevant material.
