一个从眼前问题开始的 AI 人生工作台。帮助你理解处境、作出取舍、协调时间与责任、完成具体事情，并在现实变化后继续。怎样过好，由你自己定义。

**适用于 Claude Code、Codex，以及其他支持 Agent Skills 的工具。免费开源。**

**第一次只需使用 `zane-workbench`，直接说当前要处理的事。** 它会按任务选择需要的方法；你可以从手边的一段材料开始。

## 快速开始

### 1. 安装

在终端执行：

```bash
npx -y skills add ZanePan2027/zane-life-workbench -g --all
```

也可以直接告诉 Agent：

```text
请从 https://github.com/ZanePan2027/zane-life-workbench 安装全部 Skills，
然后使用 zane-workbench，帮我处理这件事：……
```

按安装界面选择使用的 Agent，完成后按宿主要求重载。命令安装需要 Node.js 和 `npx`；项目级安装与更新见[安装说明](docs/install.md)。

### 2. 说出当前问题

```text
请使用 zane-workbench。
我在比较两份工作：一份收入更高但通勤长，另一份时间更灵活。
我想兼顾收支稳定和陪伴家人。这是两份条件和我的月度支出，
请帮我比较可行安排，说清每种选择需要承担什么。
```

这次可以先得到一份比较：两种安排各自需要多少时间和开支，哪些条件还需确认，以及下一步可以做什么。缺少影响判断的信息时，Agent 会继续追问。

### 3. 带回变化，继续处理

```text
刚确认第一份工作可以每周远程两天，请重新比较。
把比较结果和待确认条件保存到我的工作台，方便下次继续。
```

选择还没作出时，记录会保留为待决定；需要做材料、排日程或复算开支时，直接接着提出。

## 可以处理的事

| 你可以这样说 | 可以得到 |
| --- | --- |
| 两份工作各有好处，哪种更适合我现在的生活？ | 结合本人取舍、收支、时间与责任的比较 |
| 工作、陪家人和学习都想安排，这周放得下吗？ | 一周安排、冲突位置与需要调整或协商的事 |
| 想搬家，但不知道从哪里开始 | 按当前条件拆出的准备事项和下一步 |
| 我总在几种选择之间反复，想理解自己在意什么 | 根据具体经历形成的暂定认识和可以尝试的做法 |
| 上次的条件变了，这件事要怎么继续？ | 重算相关判断，更新成果与暂停点 |

## 怎样保存和继续

需要保存时，告诉 Agent 你选择的工作台文件夹。下次提供这个位置，再说“接着处理上次的工作比较”。它会读取已保存的材料，恢复当前判断和下一步。

在普通聊天中，可以先保存一份接续摘要，下次连同必要材料贴回来。只输入产品名称不会加载完整 Skill；具体做法见[聊天起步](docs/chat-start.md)。

## 按具体任务使用

日常继续使用 `zane-workbench`。熟悉后，可以直接选择问题澄清、自我认识、AI伙伴设定或工作台整理等方法；[能力目录](docs/skill-inventory.md)列出适用场景、输入示例和产出。

## 与走出象牙塔怎样选择

如果当前问题是工作、家庭、收支和个人方向之间怎样取舍，可以从这里开始。要对照岗位整理经历、制作简历和作品集、练习面试，可以使用[走出象牙塔](https://github.com/ZanePan2027/zane-career-skills)。两套工具都可独立使用。
