# 启动与适配

先检查当前宿主可读包、可写范围及可运行Python的能力，内部完成。首次使用人生、商业或职业工作台、要求建台或明确长期使用时，先连接或创建工作台，再从一件事开始；简单请求和试用直接完成。接入不等于必须整理完全部资料。

## 一次确定工作区

按以下顺序定位：

1. 使用本轮明确指定的位置或当前会话已经连接的工作台。
2. 当前项目已加载工作台规则，或项目根目录有导航、来源与状态入口时，直接沿用。会话位于项目子目录时回到已知项目根；不向上扫描项目边界之外。
3. 用户要求在当前明确的项目文件夹建台时，就地适配，包括空文件夹；已有普通资料目录也可接入，不另建套娃目录。
4. 用户明确要求在某父目录新建时，选合理子目录并说明。无明确位置、多个工作台无法辨别，或仅有主目录、磁盘根、下载目录等过大范围时，只询问会改变路径的最小问题。不得把Skill安装目录当个人工作台。

首次请求只缺位置时，说明“选择或创建一个文件夹，在Agent中打开它；已有资料直接放入或告诉我所在范围”。已提供当前问题时保留并继续不依赖位置的工作。选择位置是一次性连接，不要求每次会话重报路径；更换工具时需要在新工具中打开或授权访问同一文件夹，安装Skill本身不传递用户资料。

## 建立够用的入口

| 当前环境 | 做法 |
|---|---|
| 已有工作台／规则／事项工具 | 读取导航、当前事项和更新方式，复用其唯一状态；不初始化、不覆盖现有规则 |
| 目标目录尚不存在且有Python | 使用本目录脚本 `scripts/workbench.py init --root <新目录> --mode life|work|career`；三种模式默认加`--minimal`，后续按任务生长 |
| 已存在的空目录或普通资料目录 | 就地适配：参考assets补缺失的导航、来源映射与必要Agent入口；规则存在则合并兼容入口，保留原文。不运行init，不删除目录后重建。采用手工Markdown状态时映射其唯一位置，不创建脚本管理标记或假冒受管JSON状态 |
| 仅能读写文件 | 按当前需要写最少Markdown来源／成果／唯一状态；沿用已有系统，不要求安装Python才能使用 |
| 纯聊天 | 使用已提供材料交付实际成果；确需接续才给摘要，不声称建目录、落盘或永久记忆 |

建台授权涵盖最小入口与当前相关记录，不包含无关资料搬迁。最少入口让Agent知道在哪里找原件、当前成果和未完成点；新目录无任务时不创建虚构事项、空画像或用户未表达的目标。人生按生活问题生长，商业按业务主体与经营项目生长，职业按岗位任务与职业证据生长；不为每个Skill再建一套根目录。

## 资料进入与实际使用

告诉用户可将手头相关材料放入已有资料入口；新建最小模板使用`资料/`，用户已有收件箱就沿用。不要求先整理、改名或复制全部历史；提供已有位置时先在授权范围查找，跨工作区的材料沿用原系统支持的引用方式，不能用越界路径绕过读取工具。

整理器检查目录与文件类型，按当前任务读正文，识别来源身份、日期、版本与冲突，维护导航和来源绑定。初始归类可以先用索引，移动或改名只在本次授权范围确有必要时做，并更新引用和保留可恢复版本。历史资料整合按[资料整合与覆盖](source-integration.md)执行。

按[来源接口](source-contract.md)把本次实际目标、条件、相关事实与最近决定绑定到真实文件；模板的空绑定不代表已了解用户。使用`scripts/context.py`实际分段读取当前问题的相关来源并核对正文。手工状态也要登记在映射中，并让当前成果进入来源依赖检查范围。对话提供尚未落盘的依据时，按建台授权保留必要记录；没有资料或任务时不为了验证而虚构个人事实。

新放入文件不会因存在就自动读完。用户要求收录、整理或当前问题需要它时，检查约定资料入口与候选，读取后更新导航和引用；不承诺后台监控或会话外自动分类。发现材料、读过正文与核实事实分别说明，目录和摘要不能代替相关原文。

## 在同一工作区继续

每次从当前项目规则和导航定位相关事项、成果与必要来源，恢复实际暂停点，随后直接处理。已有持续使用授权时保存本次相关变化，不重复索要路径或保存确认。根目录清楚但当前事项有多个时，只澄清要继续哪一件。

首次完成时说明已连接的位置、材料放哪里、当前可继续的任务；已有资料则用真实内容给使用示例。用户无需理解映射或配置文件。以后提示“在同一个工作台项目里说接着上次”，只有位置改变、访问失效或对象不明时才重新定位。

核对成果可打开、来源可读、引用有效、没有第二套状态。已有任务要继续交付可用成果；纯建台请求可以以可用入口和开始方式完成，不虚构业务成果。回读实际写入后交回主控。

## 共装与同步

三包共装可共用共享组件；主责按[任务协议](task-protocol.md)选择。已有目录不随新包自动迁移，私人与组织资料保持原范围。真实权限由宿主提供，目录分开不等于访问控制。

多人或同步盘范围先看当前写者与宿主规则；同步不是跨机互斥锁。本包事项工具提供单机写入保护；已有系统使用原并发协议。可逆授权维护直接做，保留改前版本及恢复方式。
