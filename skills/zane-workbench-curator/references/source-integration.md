# 历史资料整合与覆盖

用于已有资料分散、重复索取已知信息、旧判断回流或用户明确要求全面整合。普通任务仍按最小相关来源处理。

## 先确定资料身份

在授权工作区盘点当前资料和有业务意义的历史原件；记录范围与排除项，跳过受管备份、构建副本和无关账户。用户原话、本人写作、他人反馈、AI解释、计划、行业材料、虚构案例与实际交付分开。文件名含“我”“用户”或“当前”不证明本人身份与时效；目录位置不能替代说话人和原文证据。

先处理已有个人来源与遗漏的原件。Word、PDF、表格和图片区分正文抽取、视觉读取与仅登记路径；文本抽取有缺页、图表或说话人混杂时写清边界。不能为了完整把所有聊天、第三方细节或敏感原件复制进一张画像。

## 用现有入口整合

1. 复用现有个人总览、领域事实、经历索引与唯一事项状态。总览只给理解此人的必要轮廓；详细事实有唯一来源，原件可回读。
2. 按事实发生时间和本人后续纠正建立先后关系；历史规划不当已发生，早期自评与他人评价不固定为今日人格。明确冲突而不是拼接成连贯故事。
3. 找到所有仍会被读取的相关摘要、规则与索引，撤回错误前提并指向新来源；有必要保留旧正文时显著标历史，不能只在新文末尾追加纠正。
4. 把来源角色绑定到已有问题类型映射。验证从问题能读到具体事实正文，不能只到领域目录。敏感内容只在实际相关时读取。
5. 建立能搜现有原件的入口。搜索支持历史称谓、项目名和原话；缺失、不可读、未搜索、存在但未核实分别说明。找不到不能推定用户未提供。

## 覆盖及后续变化

覆盖只记录来源治理，不创建任务状态机。区分结构发现、文字可检索、正文审阅的具体范围与审阅者（AI审阅不得称独立人工复核）、现实事实核实；有哈希/版本时用它判断审阅后变化，不能用今天重建索引给所有事实续期。

已确认的新事实回原领域源，再更新依赖它的当前摘要与取源入口。新增文件能被发现，移动/删除造成的引用缺口要显现；历史源和当前源各有使用条件。原件不可访问或全文不在当前工作区时，明确边界并交付已可完成的整合，不声称读完全部宿主历史。

## 验收

事先固定真实问题或明确标注的虚构输入，检查：

- 只在旧Word原件里存在的经历能被找到，而非再次询问本人；
- 新事实能纠正旧摘要，旧入口不能把已撤回限制带回当前建议；
- 计划里的恋爱、旅行、收入不被算成已发生；他人/AI观点不冒充本人确认；
- 一般家庭或健康问题不会加载无关第三方或私密细节；
- 新文件可发现，已审阅来源变化会显示陈旧，不能仍自称覆盖完整；
- 单纯翻译或改字仍能直接完成。

保存实际读取、原始答复和复核结果。结构检查与问答实测分别报告；没有测试的宿主、人群或长期效果不推定通过。通用发行包只包含方法、空模板和虚构测试，不能带入任何用户个人档案。
