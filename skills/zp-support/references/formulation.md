# 从经历形成可修正的问题模型

目的不是给人定性，而是让下一步帮助有依据。共同形成的问题模型（formulation）是暂时的解释，不是诊断。理论源见 [evidence.md](evidence.md) 的 P1、P2、P3、P7、P9；本文件的跨方法编排是本 Skill 的设计，尚无独立疗效验证。

## 先判断究竟要处理什么

只想被听见：跟随叙述，不启动完整建模。想理解：先得到一个贴切、可纠正的解释。想改变：明确本人希望改变的行为或生活影响。想谈意义：允许没有症状目标。只研究设计：停止个人支持路径。

改变目标可以是减少一种行为，也可以是恢复睡眠、较少自责、敢表达不同意见或承受不确定；不能由 AI 默认为效率、受欢迎或禁欲。没有确定目标时先探索，不把目标缺失当抗拒。

## 工作模型的最少要素

从已有材料提取，不逐项发问；缺什么不一定都要补齐。

| 要素 | 观察内容 | 常见误判 |
|---|---|---|
| 眼前困难 | 发生什么、本人怎么描述、影响在哪里 | 用“低自尊”代替具体事实 |
| 情境和诱发因素 | 当时的人、事、身体状态、资源与约束 | 从结果反推唯一心理原因 |
| 维持过程 | 解释、感受、行为、即时结果、延后结果的连接 | 把“有短期作用”说成“故意制造痛苦” |
| 保护与例外 | 哪次不同、已有能力、关系、现实帮助 | 只搜集支持问题叙事的证据 |
| 历史与易感背景 | 本人自愿提供且当前确实有用的经历 | 每个问题都追童年、替用户恢复记忆 |
| 未知与替代解释 | 什么没核实，至少一个可能改变下一步的解释 | 把“也许”用久了写成事实 |

发展史和维持机制要区分：知道起源不等于知道今天怎样改变；同一种行为可能在不同时刻承担不同功能。未获得历史也可做眼前支持。

## 行为链要检验功能

情境 → 当时如何理解 → 情绪／身体反应 → 行为 → 即时变化 → 后续代价或收益。

其中每一条箭头都可能未知。行为之后短暂减压且在类似情境中更易重复，才支持“负强化参与维持”的解释；负强化指去除不适增加行为发生机会，不指惩罚，也不证明有意识动机。愉悦、环境线索、疲劳、现实需要都可能是其他因素。

形成假设时在工作模型中保留三个可对照项；只把当前有帮助的部分自然告诉用户，不要求每轮展示三项：

- 暂定解释及支持它的具体材料。
- 另一个会改变帮助方式的解释，或明确承认尚不能区分。
- 能削弱主解释的观察：如环境限制解除后困难消失、行为在无压力时同样发生、本人明确否认所猜的感受。

不将用户的否认当作防御证据。本人对体验的纠正应立即采用；事实冲突另行核实，不用理论消解纠正。新证据只修正它实际触及的部分：排除一个外部要求，不等于排除所有现实负担；支持一个心理环节，也不等于证实整条循环。保留未受影响的约束，不为了迅速形成统一解释而删掉未知。

## 选择入口，避免过度心理化

真实危险、剥削、歧视、资源不足、照护责任、医疗问题：先保护、解决环境或协调资源。用户若也希望调节感受，可以并行，但不能暗示改变认知就能取消现实障碍。

缺技能：教具体技能；不必要地挖动机没有增益。目标冲突：澄清选择，不强迫承诺。情绪过载：先减少负荷，暂缓分析。重复行为：核功能与环境。反复关系困扰：先看当前互动与期待，历史仅是可选背景。持续损害明显或支持无效：考虑专业评估，不不断加深 AI 解释。

## 输出与更新

根据用户语言表达具体连接，别把固定的循环句式套在每一轮。已有资料足够就不以问题结尾；用户只想被听见时，不需要交付机制分析。模型复杂度应低于经历复杂度，不能写得比证据更确定。已形成并被认可的一部分理解可继续使用，遇到新事实再修订，不逐轮从头提出竞争解释。

如本人需要保存且已有授权，使用最少字段：本人目标、确认事实、暂定解释、反例／未知、尝试和实际反馈、暂停点。敏感内容不进入通用 Skill；当前用户暂停研究后的试用，不能被旧的“下一步练习”覆盖。
