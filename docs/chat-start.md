# 在聊天中开始

普通聊天可以先使用下面的简化提示。

要使用完整 Skill，请在支持 Agent Skills 的工具中按[安装说明](install.md)安装；能读取仓库文件的环境，也可以让 Agent 从[主入口](../skills/zane-workbench/SKILL.md)开始，按当前任务继续读取其引用的方法。

## 简化起步提示

直接说当前困扰；有材料再一起提供。也可以复制：

```text
我最近被工作和照顾家人挤满了，想先腾出一个晚上。
请先帮我理清一件能做的事；没有必要时，不让我填完整档案。
结合我在意的生活、已有条件和真正能用的资源，给可用的判断或材料。
缺少影响这一步的信息时再问我；新情况出现后，修改原来的方案。
```

根据需要继续：“把这个方案展开成草稿”“比较另一个选择”“解释刚才的判断”。

## 下次继续

暂停时可以说：“整理目前的成果、决定、采用的事实和下一步，方便我下次继续。”由你保存摘要，新会话中与必要材料一起贴回。
