# 能力目录

第一次从 `zane-workbench` 开始，由它按任务选择方法。熟悉后，可以直接使用下面的入口。

[English](skill-inventory.en.md) · [完整使用示例](guide.md)

## [统一入口](../skills/zane-workbench/SKILL.md)

`zane-workbench`

适用：理解处境、比较选择、安排生活或完成眼前任务。

```text
请使用 zane-workbench，把两份工作放进我的收支和一周安排，帮我比较。
```

产出：从本人目标出发的路线、主要未来走向、时间空间安排、可用成果和下一步。

未来方向也从此入口开始：“结合我的目标和最近变化，推演几个可能方向，告诉我现在准备什么、看到什么再改选。”方法见[未来推演与提前布局](../skills/zane-workbench/references/future-and-options.md)。

## [问题澄清](../skills/zane-question-intent-translator/SKILL.md)

`zane-question-intent-translator`

适用：几件事混在一起，还不确定当前要推进什么。

```text
请使用 zane-question-intent-translator，我同时担心换工作、收入和时间，请帮我理清现在要决定什么。
```

产出：当前问题、所需判断和可直接继续的请求。

## [自我认识](../skills/zane-self-insight/SKILL.md)

`zane-self-insight`

适用：希望从具体经历理解动机、价值或反复选择。

```text
请使用 zane-self-insight，结合这几次经历，看看我做选择时最在意什么。
```

产出：有依据的暂定认识、待确认问题和现实尝试。

## [心理支持与治疗辅助](../skills/zane-psychological-support/SKILL.md)

`zane-psychological-support`

适用：情绪困扰、反复自责、难控习惯、关系中的痛苦，或准备和复盘专业咨询。

```text
请使用 zane-psychological-support，先听我说说最近的难受。
我想理解的时候再一起探索，不用每次都安排练习。
```

产出：具体的陪伴、可纠正的理解、符合实际条件的小尝试，或咨询准备材料。按需讨论哲学与生活意义。

## [AI伙伴设定](../skills/zane-agent-identity-card-builder/SKILL.md)

`zane-agent-identity-card-builder`

适用：希望明确长期AI伙伴的协作方式。

```text
请使用 zane-agent-identity-card-builder，帮我设定一个能提出异议、说明依据并保存进展的AI伙伴。
```

产出：伙伴职责、判断方式、表达与记忆安排。

## [建台、整理与接续](../skills/zane-workbench-curator/SKILL.md)

`zane-workbench-curator`

适用：建台、整理已有资料、保存成果或接着上次。

```text
请使用 zane-workbench-curator，沿用这个文件夹建立工作台，整理已有资料的入口与引用，并接着处理当前问题。
```

产出：连接方向、个人底图、局势、路线、事项与成果的工作台，以及持续沉淀与协作方式。
