# 在聊天中开始

普通聊天可以先使用下面的简化提示。只输入“过好你的人生”这个名称，不会让 AI 自动加载仓库里的完整方法。

要使用完整 Skill，请在支持 Agent Skills 的工具中按[安装说明](install.md)安装；能读取仓库文件的环境，也可以让 Agent 从[主入口](../skills/zane-workbench/SKILL.md)开始，按当前任务继续读取其引用的方法。

## 简化起步提示

把这段话连同当前材料发给 AI：

```text
我在比较两份工作：一份收入更高但通勤长，另一份留给家人的时间更多。
请结合我的收支、家庭安排和我在意的取舍，比较可行路径。
先给能实际使用的判断或成果。缺少影响当前决定的信息时再问我。
收到新事实或修改意见后，修订相关结论与材料。
```

根据需要继续：“把这个方案展开成草稿”“比较另一个选择”“解释刚才的判断”。这段提示用于开始对话，不等于已执行完整 Skill 的来源读取与工作台维护流程。

## 下次继续

暂停时可以说：“整理目前的成果、决定、采用的事实和下一步，方便我下次继续。”由你保存摘要，新会话中与必要材料一起贴回。
