# 过好你的人生

简体中文 | [English](README.en.md)

> 从眼前一件事开始，成为越来越懂你的长期人生参谋。

[![Version](https://img.shields.io/badge/version-2.0.0-2563EB.svg?style=flat-square)](VERSION.md)
[![License](https://img.shields.io/badge/license-MIT-16A34A.svg?style=flat-square)](../../LICENSE)

这是一个陪你过日子的 AI 工作台。你可以带来一个选择、一段关系、一次转折、一个反复困扰你的问题，也可以什么都没想清楚，只说最近发生了什么。它沿一条主线陪你推进：**你想过的生活 → 当前阶段 → 人与局势 → 可能未来 → 路线与时间空间 → 做成眼前的事 → 根据反馈继续调整。**

它不帮你过性价比最高的人生，只帮你过你自己觉得值得的人生。一个下午晒着太阳睡一觉，没有任何产出，也可以是值得过的一天；什么值得，由你自己说了算。所以它先认识你：用你自己的话记住你想过怎样的生活、什么让你有劲、你的边界在哪里，再陪你把想做的事做成。

你不需要先写好目标，也不需要先整理资料。想倾诉、休息或被听懂时，陪伴本身就是一次完整的使用；想作决定时，它会陪你把理由、代价、时间、地点和退路想清楚；想继续时，它会从上次真实停下的地方回来。

**免费开源，支持豆包、WorkBuddy、Claude Code、Codex 以及其他支持 Skills 的 Agent。**

## 它能陪你做什么

| 你带来的事 | 一起得到的帮助 |
|---|---|
| 工作不错，却越来越不像自己想过的生活 | 从人生阶段和真正想保留的东西出发，比较过渡路线与下一步 |
| 对方说认可你，实际却不断加码 | 看清利益、行为和依赖，准备能用的沟通、边界和退路 |
| 局势在变，想知道接下来可能怎样 | 推演几种主要走向，找出时间窗口、提前准备和换路信号 |
| 工作、家人、身体和自己的事撞在一起 | 看整体容量，排出实际放得下的安排，减少互相挤压 |
| 想做一件事，却总在开始前停住 | 先理解卡点，再把真正愿意做的一步变成可执行的东西 |
| 最近很难受，只想先有人听 | 具体地听懂你正在经历什么；什么时候探索、练习或求助，由你决定 |
| 同一背景不想每次重讲 | 保存共同经历、当前路线和成果，让下一次更懂你 |

## 快速开始

安装后，直接告诉 Agent：

```text
使用 zane-workbench，做我的长期人生参谋。
我现在的工作收入还可以，但每天被临时任务占满。
我希望半年后能腾出时间照顾家人，也保留自己的创作。
请从我想过的生活出发，看看接下来可能怎样发展，现在怎么走。
```

它会先给你现在的建议和关键理由，再把需要的比较、安排、测算或沟通文字做出来。你可以继续说：“对方同意了，但还没有安排接替的人”，它会据此更新原来的判断。

也可以从一句更简单的话开始：

```text
我今天很累，先陪我聊聊，不急着给建议。
```

## 安装

### 快速命令

```bash
npx -y skills add ZanePan2027/zpskill -g --skill zane-workbench zane-workbench-curator zane-question-intent-translator zane-agent-identity-card-builder zane-self-insight zane-psychological-support life-decision-guide
```

### 直接告诉 Agent

```text
请从 https://github.com/ZanePan2027/zpskill 安装「过好你的人生」的 7 个 Skills（zane-workbench、zane-workbench-curator、zane-question-intent-translator、zane-agent-identity-card-builder、zane-self-insight、zane-psychological-support、life-decision-guide），
然后使用 zane-workbench，帮我处理这件事：……
```

豆包、WorkBuddy 和 Claude Code 的具体入口见[安装与更新](install.md)。

## 建立长期工作台

如果你希望 AI 记得这段共同经历，在 Agent 中打开一个准备长期使用的文件夹，然后说：

```text
把当前文件夹设为我的人生工作台。
请结合已有资料建立够用的方向、个人认识、处境、路线和进展入口，
然后陪我处理眼前这件事：……
```

相关材料可以直接放进去，也可以只告诉 Agent 它们在哪里。你不用先分类或整理完整人生，AI 会随着真实问题归拢必要内容。下次在同一个项目里说“接着上次”，它会从当时的判断、已发生的动作和下一依赖继续。

没有长期工作台也能使用：临时问题、文字修改、倾诉和一次性的比较都可以直接开始。

## 一起长出更懂你的判断

重要决定会分别留下你的想法、AI 的建议、各自依据和会改变判断的信号。现实回来后，先修当前方案，再看哪些认识值得保留。相似事情再次出现时，可以比较过去和现在真正哪里相同、哪里不同；AI 也会修正自己的误判。

需要具体生活办法时，工作台也会参考《[高性价比人生指南](https://github.com/eternity4719/HowToLiveBetter)》：发现容易遗漏的选项，比较钱、时间与精力，把相关证据变成现在用得上的安排。选哪一种，仍从你想过的生活和当前处境出发。

## 一个伙伴，几种侧重

主陪伴者会持续接住你的问题。主陪伴者负责理解你想过的生活、记住共同经历、主持取舍并把现实反馈接回来；需要时，它会让制作伙伴把方向做成稿件和成果，让调查伙伴补原件、外部事实与反例，让工具伙伴处理已经授权的外部操作。

这些伙伴共用你的目标、当前处境和动作边界。你只要自然地讲事情，不用自己调度角色，也不用向每个 Agent 重复背景。不同侧重可以带来不同意见，但最后都会回到同一条人生主线上，由主陪伴者整合成下一步。

## 能力入口

日常使用 `zane-workbench` 即可，方法会随当前问题变化。

| 能力 | 入口 | 你会得到 |
|---|---|---|
| 人生参谋、未来推演与行动 | `zane-workbench` | 推荐路线、时间空间、实际成果和下一步 |
| 理清现在真正要解决的事 | `zane-question-intent-translator` | 清楚、可继续的请求 |
| 理解动机、价值和反复选择 | `zane-self-insight` | 来自具体经历的认识和生活中的尝试 |
| 情绪陪伴与心理支持 | `zane-psychological-support` | 共同理解、适合当下的支持和咨询准备 |
| 设定长期 AI 伙伴 | `zane-agent-identity-card-builder` | 职责、判断方式、表达与协作约定 |
| 建台、整理与接续 | `zane-workbench-curator` | 资料入口、成果归拢和真实暂停点 |
| 查找具体生活办法 | `life-decision-guide` | 按需参考指南条目，补充候选和出处 |

完整用法见[教程](guide.md)、[工作台结构](architecture.md)和[能力目录](skill-inventory.md)。
