# 信息沉淀与认识成长

用户照常提问和带回变化，AI负责把有用信息放回合适的位置。

| 信息 | 保存与影响 |
|---|---|
| 本人目标或取舍 | 方向；同步阶段、相关路线和已接受承诺 |
| 本人经历、偏好、能力 | 个人底图；具体原话与来源保留 |
| 钱、时间、身体、地点等条件 | 对应事实原页；更新资源判断与可行安排 |
| 人物行为、关系和承诺 | 原始记录＋人物研判；按行为修正信任与响应预测 |
| 一次完整计策与重要分歧 | 当前路线；按提出者与信息时点保留事前判断，引用原件、原事项与可用成果 |
| 现实动作、反馈 | 原事项；重算当前判断并修改相关成品 |
| 跨事项经验与成长 | 从原事件提炼条件、反例、成功做法、新能力和下次帮助；AI误判也留修正 |

首次保存保留说话人、事实日期、记录日期及来源。原件提供细节，当前提炼承接认识；AI解释随新事实修正。本人体验与取舍、对外界的解释、确认决定、实际动作分开；目录位置不赋予真假。事实出现冲突时保留两方出处，先核影响当前选择的部分。

本人和AI的重要事前判断放在原事项引用的路线或成果中，分别保留实际主张、依据、信息截止及改判条件。当前状态仍由原事项维护，历史版本沿已有备份或带日期的原段保留。事后重建标记重建时间、直接出处与缺口，不能补造当时判断。同一经历的多份材料归同一来源单元，不当成独立支持。

新事实的闭环：保留原始反馈→查来源依赖→改当前判断和实际成果→写回原事项→调整阶段或本人认识→从下一会话入口回读。使用来源接口的workbench-sources与impact连接当前成果；重要遗漏继续按语义查找。

目标变化时保留本人新原话，重算相关路线和承诺，把旧目标及推荐留作历史。人物认识只在相应关系和情境使用；有成本的善意和守约可增加信任，失约或利益变化重新比较。

经验记录回答：当时双方各知道什么、怎样预测和准备、实际做了什么、后来发生什么、条件有何变化、差异怎样解释、下次怎么做。尚待观察的预测保留原判断和窗口；新反馈分别评价预测、准备价值和本人适配，AI误判同样修订。成功条件和新能力要有直接来源；单次不定人格，过时模式在当前入口撤回并保留替代关系。用户自己报告的感受和投入是判断帮助是否值得的重要依据。

具体判断由当前主方法完成，整理器不凭文件数量生成置信度或替本人改目标。没有新的可复用认识就不增加经验条目；日常表达、陪伴和休息不自动转成记录任务。

接续只读取当前任务相关的认识和事实；概要帮助定位，关键判断回原文。单次情绪先在本次处境中理解，敏感记录依已有授权和对应方法保存。
