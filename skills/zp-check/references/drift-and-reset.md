# 偏离与重开

## 怎么看出偏了

- 现在做的东西，最初的原话里没有提过。
- 要求越来越多，却没有人说清哪些是必须的。
- AI 回复越来越长，开始解释它自己的做法，而不是给你要的东西。
- 你自己回答不出“这一步是为了最初哪个目标”。
- 你发现最初的一条要求已经被悄悄忘了。

## 三张清单

1. **已定下的要求**：你明确说过、而且仍然有效的。AI 提议、你只回了“好的／可以”的，**不算**你提出的要求：放进第 2 张清单，并标注“AI 提议，用户应允”，由用户决定留不留，不要当成已定要求，也不要擅自删掉。
2. **AI 自己加进来的假设**：你没说过，但它当成了前提。
3. **被忘掉的要求**：你说过，但最近几轮没有体现。

## 判断

- 第 2、3 张几乎是空的：在轨，继续。
- 有一两项：轻微偏离。一句话拉回：“回到最初：……。把……去掉，把……补回来。”
- 第 2 张很长，或第 3 张里有重要的要求，或你已经说不清当前版本是什么：严重偏离，重开。

## 重开简报模板

新开一个对话，第一条消息一次说全：

```
我要做的事：……（一句话）
最终要交付：……
必须满足：……（只列真正有效的要求）
明确不要：……（包括之前对话里被你否掉的方向）
已确定的事实：……
已经做出且要保留的部分：……（原文或要点）
先不要做：……
做完后我会这样检查：……
```

写简报时，把第 2 张清单里被你否定的假设写进“明确不要”，被忘掉的要求写进“必须满足”。

## 为什么要重开

研究发现，主流模型在多轮对话里表现明显比一次说全差：它们容易在前几轮就做出假设、过早给出最终方案，并在后面过度依赖，走错一步后很难恢复；系统自动做回顾之类的补救并不够（Laban 等 2025）。所以走偏之后，用一份完整简报重开，通常比在原对话里继续纠正更可靠。
