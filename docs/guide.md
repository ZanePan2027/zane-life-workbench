# 从一个问题开始，想继续时再保存

安装后使用 `zane-workbench`，直接说当前问题；普通聊天也可先用简化提示。没有资料、完整目标或文件夹时，先获得帮助。[安装与更新](install.md) · [能力目录](skill-inventory.md) · [English](guide.en.md)

## 先处理一件你在意的事

例如：“我想每周陪爸爸聊一会儿，不想做打卡计划。周二晚有半小时，他喜欢聊老电影。”AI可以先给一个轻松的起点：“周二要不要一起看看你喜欢的老电影？想聊就聊，累了就停。”不用先建立档案，也不把陪伴变成效率目标。

后来爸爸说周二累、周末更愿意聊，就按双方愿望改安排。是否真正聊过、体验怎样，以后带回反馈再看；没有回报消息也不等于失败。

下面用一个需要保存的工作比较，演示怎样持续使用。

## 需要保存时，连接一个文件夹

在Agent里打开准备长期使用的项目文件夹，说：

```text
请使用 zane-workbench，把当前文件夹设为我的人生工作台。
沿用里面已有的规则和资料，帮我建立够用的入口。
```

已有工作台直接沿用，普通资料目录或空目录也可接入。没有选位置时，让Agent引导确定一次保存位置。之后在这个项目里使用，无需每次重报路径。

## 接入手头材料

把与当前问题有关的文件放进约定资料入口，或告诉Agent已有资料的位置。新建工作台通常使用`资料/`，已有收件箱可以沿用。无需自己先分类，也不必把全部个人历史搬进来。

例如，已有两份工作条件、一份月度支出表，可以说：

```text
这些是两份工作条件和我的月度支出。
请整理可查找的入口，保留原件，并读出本次比较需要的事实。
```

Agent 整理资料入口，读取当前问题需要的内容。没有资料也可以从对话开始，必要信息按本次任务补充。

## 说出眼前的选择

```text
我在比较两份工作：A 收入高但通勤长，B 收入稍低但时间灵活。
我现在最在意收支稳定，以及每周能陪家人多少时间。
请结合工作台里的条件与支出材料，帮我比较。
```

AI会读取相关正文，结合收入、必要开支、时间和家庭安排，说清哪些条件最影响判断，哪些还没有确认。

## 把选择展开到生活里

继续说：“把两种选择分别放进一周安排，看看时间和现金是否够用。”

得到具体安排后，可以补充偏好：“我愿意少一些收入，换每周两个完整晚上。”AI据此调整选项。相关来源、成果和暂停点按建台授权保存；建议不会被记作你已经接受的决定。

## 带回新条件

例如：“A提供每周两天远程办公。”AI应更新原来的比较与当前记录，重算通勤和陪伴时间。若是新增文件，可以说“把新资料收进工作台”，由Agent读取、关联和更新入口。

## 下次直接继续

打开同一个工作台项目，告诉AI：“接着上次的工作比较。”它会自己读取当前事项、相关成果与来源，再继续处理；多个事项无法辨别时，只需说明继续哪一件。

只有换了项目、文件夹不可访问或工作台位置有歧义时，才需要重新定位。换工具时在新工具里打开或授权访问同一文件夹。

临时问题可以直接问，不必先建台。普通聊天无法读写文件时，使用[聊天起步](chat-start.md)，保存接续摘要并在下次贴回。
