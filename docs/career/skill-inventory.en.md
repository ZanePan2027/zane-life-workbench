# Skill directory

Start with `zp-career`. It selects the methods needed for your task. Use a specific entry below when its purpose fits.

[简体中文](skill-inventory.md) · [Walkthrough](guide.en.md)

## [Main entry](../../skills/zp-career/SKILL.md)

`zp-career`

Use when: Choosing roles, finding openings, using recruitment platforms, making application materials, preparing for assessments and interviews, comparing offers, or preparing to start.

```text
Use zp-career. Here is my experience and two job descriptions. Help me compare them.
```

Output: The result needed for the current task: a decision, file, message or turn-by-turn practice. No workbench setup is required.

## [Complete application materials](../../skills/zp-materials/SKILL.md)

`zp-materials`

Use when: Producing a resume, portfolio, and application entry points together.

```text
Use zp-materials. Use this target role and material to plan and produce the application materials I need.
```

Output: Roles for each format, content, design, and deliverable files.

## [Resume creation](../../skills/zp-resume/SKILL.md)

`zp-resume`

Use when: Creating a resume or adapting it to a hiring market and language.

```text
Use zp-resume. Use these experiences for an English resume for a product internship.
```

Output: Resume content, layout, and editable/PDF files supported by the environment.

## [Portfolio structure](../../skills/zp-portfolio/SKILL.md)

`zp-portfolio`

Use when: Planning how recruiters read several projects.

```text
Use zp-portfolio. How should these three projects be divided between the homepage and detailed cases?
```

Output: Structure for the homepage, detailed cases, and project index.

## [Portfolio website](../../skills/zp-site/SKILL.md)

`zp-site`

Use when: Designing or implementing a recruitment portfolio.

```text
Use zp-site. Build a portfolio website using the confirmed project content.
```

Output: Page design, responsive implementation, and local files.

## [Chinese case editing](../../skills/zp-editor/SKILL.md)

`zp-editor`

Use when: Editing a Chinese case whose facts are already confirmed.

```text
Use zp-editor. Keep the facts and make this Chinese project case clearer, removing empty summaries.
```

Output: A revised case preserving the facts, with relevant editing notes.

## [Contribution and outcomes](../../skills/zp-story/SKILL.md)

`zp-story`

Use when: Presenting leadership responsibility, collaboration and outcomes accurately.

```text
Use zp-story. Turn this case into convincing application copy that reflects my actual responsibilities.
```

Output: Credible case copy. Accountable team outcomes are valid leadership achievements; shared execution does not automatically weaken them.

## [Employer material](../../skills/zp-redact/SKILL.md)

`zp-redact`

Use when: Preparing a case that contains former-employer information.

```text
Use zp-redact. Check what in this case can be shared publicly, replaced, or discussed in an interview.
```

Output: Material review, alternative wording, and recommendations on sharing scope.

## [Application opening](../../skills/zp-greeting/SKILL.md)

`zp-greeting`

Use when: Writing a first message to a recruiter.

```text
Use zp-greeting. Write a short opening message using this role and my resume.
```

Output: A draft suited to the role, channel, and language.

## [Delivery checks](../../skills/zp-qa/SKILL.md)

`zp-qa`

Use when: Checking completed resumes, websites, or portfolios.

```text
Use zp-qa. Check this PDF and portfolio page for layout, links, and mobile display.
```

Output: Observed results, issue locations, and any checks that could not be performed.

## [Design reference interpretation](../../skills/zp-design-prompt/SKILL.md)

`zp-design-prompt`

Use when: Turning a webpage or screenshot reference into design requirements.

```text
Use zp-design-prompt. Translate this reference page into design requirements for my portfolio.
```

Output: An explanation of visual relationships and actionable design requirements.
