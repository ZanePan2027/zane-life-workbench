# 高性价比人生指南：外部证据连接器

这是 `zane-workbench` 的可选外部来源适配器，不是一套独立的人生观，也不维护第二套事件状态。它负责把外部指南的条目查清楚，再交回 `zane-workbench` 按本人北极星、自有人生知识层、当前阶段、现实约束和反馈完成判断。没有网络或上游仓库不可用时，主工作台仍继续运行，并明确哪些外部证据未核验。

它不把《高性价比人生指南》正文变成工作台资产，不复制 667 条建议，不把作者排序写成用户价值排序，也不替本人持有当前政策、医疗、法律或事件状态。

## 使用顺序

1. **先判断是否需要立即行动**：急救、火灾、溺水、中毒、严重出血、卒中／心梗症状、现实中的自杀风险或正在进行的刑事程序，先给 120／119／12356／律师等当下入口和第一动作，再做解释。
2. **取当前正文**：优先使用工作台的固定提交读取器；没有网络或读取失败时，明确写“外部指南未核验”，不凭记忆复述。仓库地址为 `https://github.com/eternity4719/HowToLiveBetter`。
3. **定位章节**：先读工作台目录与 README，再选 1—3 个章节；不在未核对目录时猜文件名。当前固定提交和读取入口见下方命令。
4. **整条读取**：必须读完条目的成本、说人话、收益、证据等级、来源和备注，保留适用人群、争议、例外和事实日期；命令的 `sha256` 与 `commit` 要随内部证据保存。
5. **分开排序**：分别列钱、时间、精力、毅力成本，以及寿命、时间与精力、金钱、人身自由收益；同一收益口径内才比较性价比。证据等级和性价比是两条轴。
6. **只选少数动作**：给 1—3 条当前可执行、可验证的动作，并写采用条件、受益人、外部风险、退出成本和改判信号。没有采用的条目保持候选。
7. **交回主 Skill**：把结果交给 `zane-workbench`，由它补读本人方向、阶段、相关事实和现实事项，完成路线、行动和反馈回写。

## 固定提交读取入口

工作台不复制指南的 667 条正文；本地工作台需要时按章节读取已审阅提交：

```bash
python3 tools/life-guide.py --catalog
python3 tools/life-guide.py --chapter '19-在职离职和工伤.md'
```

默认提交为 `20718eeab32cb8506971fb71b03e66a91077be07`。需要更新时先重新审阅提交、目录和条目，再改工具常量与本地来源说明；不把 `main` 的最新内容自动当成当前正文。`--max-chars` 只能做定位预览，不能当作完整条目证据。

导出到没有 `tools/life-guide.py` 的宿主时，使用宿主可用的只读 HTTP／浏览器工具读取同一提交的 `README.md` 和 `book/*.md`，并保留相同的 `commit`、路径和正文 SHA-256；宿主无法读取或无法保留完整正文时，报告“指南未核验”，不要退回分支最新内容或模型记忆。

本 Skill 只提供来源索引和外部核验；你的商业产品应销售自有方法、案例、个性化判断、交付和反馈服务，不把上游正文包装成独占内容。来源身份和固定提交记录在本地知识层的来源注册表中。

## 事实边界

指南正文不是本人事实，也不是今日政策数据库。正文没有的数字、法条、症状、机制、政策金额和截止日期不得补写；动态内容要查当期官方来源。涉及具体病情、案件、税务或投资，只给通用方向和该找谁，不代替医生、律师、会计或投资顾问。

指南的作者排序只减少检索成本，不替本人决定优先级。本人幸福、关系、信仰、创造、体验和主体性保留直接价值；四类收益不合并成人生总分。对外部建议的采用必须经过本人当前阶段和容量核对，采用后才能进入原事项的 action 或 evidence。

## 输出格式

- **先按问题密度回答**：简单、低风险、只需要一个判断的问题，先用自然语言给结论和第一步；只在它会改变选择时顺带写条目、成本或证据。不要为了格式完整补空栏，也不要把内部核验过程逐项讲给用户。
- **需要比较或核验时**：再给 1—3 条动作、成本、收益、证据等级、章节／条目和适用条件；不建议或反面清单只写会改变决定的部分。
- **高风险或用户主动要求来源时**：补齐指南没有覆盖的内容、事实日期、复查时间和改判信号，并明确哪些内容需要当期官方或专业核对。
- 无论使用哪种密度，结论都先回到本人处境和当前决定；指南只是证据入口，不是答复的固定外壳。
